# 🔢 Интерактивный счётчик (Counter App)

**Кейс-задача № 2** — Веб-приложение счётчика с визуальными индикаторами состояния и ограничениями значений.

---

## 📋 Описание

Простое интерактивное приложение-счётчик с динамически изменяющимся интерфейсом в зависимости от значения. Счётчик изменяется в диапазоне от **-10 до +10** с визуальной индикацией и блокировкой кнопок на границах.

---

## ✨ Функциональность

### Реализованные возможности:

1. **Увеличение/уменьшение значения** — кнопки "+" и "−" изменяют счётчик на единицу
2. **Динамическое изменение цвета фона** — в зависимости от значения:
   - **Жёлтый** — положительные значения (> 0)
   - **Зелёный** — отрицательные значения (< 0)
   - **Красный** — ноль (= 0)
3. **Блокировка кнопок** — автоматическая деактивация при достижении границ:
   - Кнопка "+" блокируется при значении **10**
   - Кнопка "−" блокируется при значении **-10**
4. **Уведомление о границе** — сообщение "Вы достигли экстремального значения" при ±10
5. **Плавные переходы** — анимация изменения цветов и состояний

---

## 🎨 Дизайн

### Стилистика:

- **Фон страницы:** Градиент от индиго через фиолетовый к розовому
- **Окно результата:** 140×140px, скругление 5px, крупный шрифт
- **Кнопки:** 
  - Радиус скругления: 5px
  - Градиентный фон (синий для "−", зелёный для "+")
  - Эффект hover
  - Визуальная индикация disabled состояния (40% прозрачности)
- **Центрирование:** Flexbox для вертикального и горизонтального выравнивания
- **Плавность:** CSS transitions для всех изменений цвета

## 🛠️ Технические детали

### Архитектура кода:

```javascript
// Состояние приложения
let count = 0;

// Элементы DOM (кешируются при загрузке)
const resultEl = document.getElementById('result');
const plusBtn = document.getElementById('plus');
const minusBtn = document.getElementById('minus');
const messageEl = document.getElementById('message');

// Функции отрисовки
updateBackground()  // Обновление цвета фона
updateButtons()     // Управление состоянием кнопок
updateMessage()     // Отображение сообщения
render()            // Главная функция отрисовки
```

### Логика изменения цвета:

```javascript
if (count > 0) → Жёлтый фон
if (count < 0) → Зелёный фон
if (count === 0) → Красный фон
```

### Логика блокировки кнопок:

```javascript
plusBtn.disabled = (count === 10)    // Блокировка на максимуме
minusBtn.disabled = (count === -10)  // Блокировка на минимуме
```

### Обработчики событий:

```javascript
// Кнопка "+"
plusBtn.addEventListener('click', () => {
  if (count < 10) {
    count++;
    render();
  }
});

// Кнопка "−"
minusBtn.addEventListener('click', () => {
  if (count > -10) {
    count--;
    render();
  }
});
```

## 📝 Примечания

### Почему используется Tailwind через CDN?

Для учебного проекта это самый быстрый способ получить modern UI. В продакшене рекомендуется локальная сборка с PurgeCSS для оптимизации размера.

### Паттерн архитектуры:

Приложение следует паттерну **"Unidirectional Data Flow"**:
```
Событие → Изменение состояния → Рендер UI
```

Все изменения UI проходят через функцию `render()`, что обеспечивает консистентность интерфейса.

### Оптимизация производительности:

- DOM элементы кешируются при загрузке (не ищутся каждый раз)
- Используются CSS transitions вместо JavaScript анимаций
- Минимальное количество DOM манипуляций
