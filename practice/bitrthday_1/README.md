# 🎂 Программа стилистического преобразования даты рождения

**Кейс-задача № 1** — Консольное приложение для анализа даты рождения пользователя с выводом в виде электронного табло.

---

## 📋 Описание

Программа запрашивает дату рождения пользователя и выполняет следующий анализ:
- Определяет день недели рождения
- Проверяет, был ли год високосным
- Вычисляет текущий возраст
- Выводит дату в формате электронного табло (звёздочками)

---

## ✨ Функциональность

### Реализованные функции:

1. **`get_date_input()`** — запрашивает у пользователя день, месяц и год рождения
2. **`day_of_week(day, month, year)`** — определяет день недели по дате
3. **`is_leap_year(year)`** — проверяет, является ли год високосным
4. **`calculate_age(day, month, year)`** — вычисляет текущий возраст
5. **`print_star_date(day, month, year)`** — выводит дату звёздочками в формате `дд мм гггг`

## 🛠️ Технические детали

### Алгоритм определения дня недели:
Использует встроенный метод `datetime.weekday()`, который возвращает индекс дня недели (0 = понедельник, 6 = воскресенье).

### Алгоритм проверки високосного года:
```python
(year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)
```
- Год делится на 4 **И** не делится на 100 **ИЛИ** делится на 400

### Вычисление возраста:
```python
age = today.year - year
if (today.month, today.day) < (month, day):
    age -= 1
```
Учитывает, прошёл ли день рождения в текущем году.

### Электронное табло:
Каждая цифра представлена 5 строками и 3 столбцами символов:
```
***   <- строка 1
* *   <- строка 2
***   <- строка 3
* *   <- строка 4
***   <- строка 5
```
